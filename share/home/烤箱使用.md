# 烤箱常用用途 · 笔记

> 一句话记住：烤箱 = **烤肉 + 烘焙 + 蔬菜增甜 + 零食自制 + 低温发酵/烘干**

---

## 一、🥩 肉类（高频主力）

| 品类 | 常见做法 | 参考温度/时间 |
|---|---|---|
| 鸡翅 | 奥尔良烤翅、蜜汁烤翅 | 200℃ / 20–25 min |
| 整鸡 | 脆皮烤鸡、窑鸡 | 180–200℃ / 60–90 min |
| 羊排 | 孜然烤羊排 | 200℃ / 25–30 min |
| 牛排 | 先煎后烤锁汁 | 220℃ / 6–10 min |
| 排骨 | 蜜汁猪肋排 | 180℃ / 40 min |
| 海鲜 | 烤鱼、大虾、生蚝、扇贝 | 200℃ / 10–20 min |

**要点**：腌够时间 + 高温上色 + 出炉静置 5 min 再切。

---

## 二、🍰 烘焙甜点（烤箱的"本职"）

- **蛋糕**：戚风、芝士、古早、纸杯
- **饼干**：曲奇、蔓越莓饼干、玛格丽特
- **面包**：吐司、软欧、贝果、餐包
- **派/挞**：蛋挞（新手首选）、苹果派、葡挞
- **泡芙 / 马卡龙**（进阶）

> 新手三件套：**蛋挞 → 曲奇 → 戚风**

---

## 三、🥔 蔬菜（被低估的香）

- 根茎类：土豆、南瓜、胡萝卜、玉米 → 烤出**焦香+天然甜**
- 菌菇类：口蘑、金针菇、杏鲍菇
- 混合：**地中海烤时蔬**（彩椒+西兰花+小番茄+洋葱 + 橄榄油 + 黑胡椒 + 盐，200℃ / 20 min）

---

## 四、🍟 主食 & 快餐平替

- 披萨（半成品或自制饼底）
- 烤饭团 / 焗饭 / 芝士意面
- 烤薯条、烤鸡米花（少油版炸物）
- 烤冷三明治、帕尼尼

---

## 五、💡 隐藏用法（很实用）

| 用途 | 怎么做 |
|---|---|
| 复脆 | 受潮饼干/薯片/坚果，150℃ / 3–5 min |
| 烘干 | 水果干、牛肉干、柠檬片（100℃ 上下，长时间） |
| 发面 | 烤箱发酵档 28–35℃，放一碗热水保湿 |
| 做酸奶/米酒 | 发酵档 40℃ 左右，6–10 h |
| 解冻 | 50–80℃ 低温，比室温卫生、比微波均匀 |
| 烤坚果 | 花生/核桃/杏仁 160℃ / 8–10 min |
| 烤水果 | 烤橘子（止咳）、烤梨（秋冬润燥）、烤苹果 |

---

## 六、⚠️ 安全红线

- ❌ 普通塑料盒、保鲜盒、外卖盒 → **不能进烤箱**
- ❌ 普通玻璃（非耐热）→ 可能炸裂，认准 **耐热玻璃 / 高硼硅**
- ❌ 密封容器 → 会爆
- ✅ 可用：**陶瓷、铸铁、高硼硅玻璃、锡纸、油纸、硅胶垫**
- 🔥 取盘一律戴**隔热手套**，开门先开一条缝散蒸汽

---

## 七、🌡️ 常用温度速查

```
100℃  烘干 / 低温慢烤 / 做酸奶
150℃  复脆 / 蛋糕慢烤
180℃  万能温度：鸡翅、饼干、面包
200℃  烤肉、披萨、蛋挞、蔬菜
220℃  烤红薯、脆皮、上色
230℃+ 猛火收尾（最后 3–5 min 上色）
```

---

## 八、✅ 新手零失败三连

1. **烤红薯**：220℃ / 40–60 min（不用预热也行）
2. **奥尔良鸡翅**：200℃ / 25 min（中途翻面刷蜂蜜）
3. **蛋挞**：200℃ / 25 min（买现成挞皮 + 挞液）

> 记住一句：**先预热、别频繁开门、出炉必静置。**
