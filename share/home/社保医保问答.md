# 农村户口·社保/医保/养老保险 知识笔记（问答版）

> 适用背景：河北邢台及周边县域农村居民，兼顾全国通用规则
> 数据截止：2026年11月。文中河北/邢台口径以当年官方公告为准，办业务前建议再用"河北税务"公众号或村委会核对一遍

---

## 一、先把概念理清楚（最容易被绕晕的部分）

### Q1：社保、医保、养老保险到底什么关系？

一句话：**社保是个大筐，医保和养老保险是筐里两个最常用的篮子。**

```
社会保险（"五险"）
├─ ① 基本养老保险 ← 老了按月领钱
├─ ② 基本医疗保险 ← 看病报销（农村过去叫"新农合"，现已并入城乡居民医保）
├─ ③ 工伤保险     ← 干活受伤（个人不缴费，单位缴）
├─ ④ 失业保险     ← 非本人意愿失业领失业金
└─ ⑤ 生育保险     ← 生孩子报销+生育津贴（个人不缴费，单位缴）
```

农村户口居民日常打交道最多的是 **① 养老** 和 **② 医疗**，也就是村里常说的"**两险**"或"**居民两险**"。

### Q2："新农保""新农合"现在还有吗？

**名号已经合并，但底层还在。**

- 新农保（农村养老）+ 城居保（城镇无业居民养老）→ 2014年合并为 **城乡居民基本养老保险**
- 新农合（农村合作医疗）+ 城镇居民医保 → 陆续合并为 **城乡居民基本医疗保险**

所以现在填表、缴费看到的名字都是"**城乡居民**"，不再分农村城镇，但**缴费仍要在户籍地**（养老）或**居住地/户籍地**（医保）。

### Q3：农村户口有哪几条参保路线？

| 身份 | 养老走哪条 | 医保走哪条 |
|---|---|---|
| 在家种地、打零工、没单位 | 城乡居民养老保险 | 城乡居民医保 |
| 进城务工、跟单位签合同 | **职工养老**（单位必须缴，五险全套） | **职工医保** |
| 灵活就业（摆摊、跑车、接活） | 二选一：灵活就业职工养老 **或** 城乡居民养老 | 二选一：灵活就业职工医保 **或** 城乡居民医保 |
| 在校学生、未成年人 | 不缴养老 | 随父母参加城乡居民医保 |
| 低保/特困/重度残疾/防返贫监测对象 | 政府代缴或补贴（河北按100元档代缴） | 全额或部分资助，个人少缴或不缴 |

> ⚠️ **关键规则**：同一个人、同一时间段，**养老只能参加一种**，**医保只能参加一种**，重复参保也不会领双份钱，重复那段只算职工、居民那份退还本人。

## 二、城乡居民养老保险（农村最常用）

### Q4：谁能参加？多少钱一档？

**年满16周岁（不含在校学生）、没参加职工养老、非机关事业单位人员**，在户籍地自愿参加，60周岁起按月领。

**河北/邢台2026年度档次与政府补贴**（补缴年份**不享受补贴**）：

| 档次 | 200 | 300 | 500 | 1000 | 3000 | 5000 | 8000 |
|---|---|---|---|---|---|---|---|
| 政府补贴 | 30 | 45 | 60 | 75 | 90 | 105 | 120 |
| 困难群体 | 低保、特困、重度残疾等由政府按**100元档代缴**，个人不掏 | | | | | | |

**缴费时间**：河北集中征缴一般 **9月/10月—11月25日**，每月 **1—25日**可缴，26日到月底是税务结算期缴不了。

**缴费渠道**："河北税务"微信公众号 / 支付宝"河北社保云缴费" / 微信城市服务 / 村委会代办 / 乡镇行政综合服务中心 / 银行网点。

### Q5：一个月能领多少钱？怎么算？

**月养老金 = 基础养老金（政府定额） + 个人账户总额 ÷ 139**

- 基础养老金：国家和省里定底线，各县可加。河北县域目前大致 **200—220元/月**上下（如玉田218元、部分县211元），**每多缴1年再加一点**，具体看本县公告
- 个人账户 = 个人历年缴费 + 政府补贴 + 村集体补助 + 利息（2026年河北记账利率 **3.63%**，比定存高，复利滚）
- 139 是国家统一"计发月数"（对应60周岁）

**粗算示例**（不含利息、按基础养老金218元）：

| 缴费选择（缴满15年） | 60岁后月领约 |
|---|---|
| 200元档 | **243元** |
| 1000元档 | 约 350元 |
| 8000元档 | **约1094元** |

> 💡 父母已过60、当年没缴过高档的，子女可以做"**资助缴费**"（支付宝市民中心→社保缴费→个人资助），金额不超最高档，直接给老人账户加钱，当月就能体现在养老金里。

### Q6：断缴/漏缴会怎样？会不会清零？

**不会清零，但有三笔隐形损失：**

1. **政府补贴没了**：正常当年缴才有30—120元补贴，**补缴往年一律不给**
2. **利息少滚几年**：缴费到账次月起才计息，3.63%复利，拖一年亏一年
3. **年限不够就不能按时领**：60周岁时累计不满15年，就得**延后缴到满15年才开领**，等于晚几年拿钱

### Q7：到60岁不够15年怎么办？能一次性补吗？

**目前（2026—2028年）多数省份还允许一次性补缴至15年，但窗口正在关闭。**

- 现行规则：制度实施时（多地2014年前后）距60岁不足15年的，可逐年缴+补缴，累计不超15年，**补缴无补贴**
- **重要风向**：已有省份明确 **提档补缴执行到2027年底、一次性补缴执行到2028年底**，2029年起60岁不够15年只能**逐年顺延**，缴满才领，等于自动延迟退休
- 河北目前仍可办，但**别赌政策一直在**，家里有58、59岁年限不够的，**今年就补掉**

### Q8：人没了，交的钱打水漂吗？

**不会。**

- 无论领没领过待遇，个人账户**余额（含政府补贴和利息）全额由法定继承人继承**
- 另发**丧葬补助金**，河北城乡居民口径一般为**上年度基础养老金的一定月数**（如通城按12个月），无抚恤金；职工养老的丧葬费+抚恤金标准比居民高得多

## 三、城乡居民医保（原"新农合"）

### Q9：2027年交多少钱？什么时候交？

**河北2027年度口径**：

- 个人缴费 **400元/人**（连续第三年没涨）
- 财政补助 **724元/人**（政府拿大头，约六成半）
- 集中征缴期：**2026年10月10日 — 2027年1月底**
  - **2026年12月31日前**缴 → 2027年1月1日起全年待遇
  - 2027年1月1—31日缴 → **缴费到账之日起**享受待遇
- 困难群体资助：特困/孤儿**全额代缴**；低保、防返贫监测对象个人缴**40元**；二级以上重度残疾个人缴**160元**（各市略有差异）

### Q10：错过了集中缴费期会怎样？（2025年起新规，最重要）

**自2025年起国家设了"待遇等待期"，断缴代价明显变大**：

```
总等待期 = 固定3个月 + 变动（每断保1年 +1个月）
固定3个月不可修复；变动部分可"缴费修复"，多缴1年减1个月
连续断缴 ≥4年：修复后总等待期仍不少于6个月
```

**举个例子**（河北口径）：

| 情况 | 什么时候能报销 |
|---|---|
| 2025、2026都正常缴，2026年12月前缴2027年的 | 2027.1.1 起，全年无忧 ✅ |
| 上面这位拖到2027年2月才缴 | 3个月等待期，**5月1日**才能报 ❌ |
| 2026年断保，2027年2月缴 | 3+1=**4个月**等待期，5月1日后……实际6月1日 ❌ |
| 2025、2026连断两年，2027年集中期缴 | 3+1=4个月，5月1日起；若再花400元修复1个月 → 4月1日起 |

> ⚠️ **等待期内住院，一分不报，全自费**。这是断缴最疼的一刀，比养老断缴狠得多。
> 另有省份规定：断保后即使过了等待期，**大病保险最高支付限额也会下调**（如贵州降2%）。

### Q11：新生儿、当兵回来、职工转居民，也要等3个月吗？

**这几类是"豁免户"，不受等待期限制**：

- **新生儿**：出生 **90天内**参保缴费 → 从**出生那天**起享受待遇，回溯报销出生时的住院费
- 职工医保断保 **3个月内**转居民医保 → 缴费到账次月起享受，不加等待期
- 退役军人、随军未就业家属、刑满释放1年内、动态新增医疗救助对象

### Q12：居民医保有个人账户吗？能给家人用吗？

- 河北城乡居民医保**没有个人账户**（钱全进统筹基金），所以不存在"账户余额清零"的说法
- 但**职工医保个人账户可以家庭共济**：在河北智慧医保小程序绑定父母子女后，用你的职工个账帮他们缴400元居民医保、付门诊自费
- 别信"医保断缴3个月个人账户清零"——**职工医保个账余额永远不会清零**，清零的只是"连续缴费年限"和当期报销资格

## 四、进城务工：职工社保（含金量最高，别放弃）

### Q13：厂里/工地上说"农村户口不用交社保，多给你200块"，能答应吗？

**不能。这是违法操作，吃亏的是你。**

- 《社会保险法》和人社部明确：包括**非城镇户口职工在内，所有单位职工都必须参加五险**，农村户口和城镇户口**同政策、同待遇**
- 养老、医疗、失业：单位+个人共同缴；**工伤、生育：单位全掏，个人一分不缴**
- 签"自愿放弃社保"的承诺书**无效**，将来照样可以要求单位补缴、可以要求经济补偿
- **保留证据**：劳动合同、工资条、考勤、微信派活记录、工牌。真不缴，打 **12333** 投诉或去县人社局劳动监察大队

### Q14：职工养老和城乡居民养老，哪个划算？

| 对比项 | 职工养老（灵活就业/单位） | 城乡居民养老 |
|---|---|---|
| 年缴费（河北最低档参考） | 灵活就业约 **9000—12000元/年**（社平60%×20%） | 200—8000元/年，自选 |
| 谁掏钱 | 单位职工个人只出8%；灵活就业全额自掏20% | 全自掏，政府补一点 |
| 领取年龄 | 男60（渐进延迟中）、女55/50 | **男女一律60** |
| 最低年限 | 2029年前15年，2030起逐步提到**20年** | 15年 |
| 待遇水平 | 挂钩社平工资，月领通常 **1500—3000元+**，每年普调 | 月领 **240—1100元**，基础养老金不定期小调 |
| 丧葬抚恤 | 有，标准高 | 只有丧葬补助，无抚恤金 |
| 断缴补缴 | 灵活就业**当年不能往前补**（部分地市已收紧） | 目前可补（2028年后或收紧） |

**选型口诀**：

- **男40岁前 / 女35岁前**，能长期稳定挣钱 → 优先**灵活就业职工养老**，20年下来回本快、涨得多
- **男45+ / 女40+**，凑20年已过退休年龄 → 老实缴**城乡居民养老**，选3000—8000高档，60岁准时开领
- 在厂里上班 → **不用选，单位必须给你上职工五险**，这是法定

### Q15：两种养老都交过，最后怎么合？

按《城乡养老保险制度衔接暂行办法》（人社部发〔2014〕17号），**到退休年龄时**办一次衔接，不能同时领两份：

| 情形 | 怎么合 | 按哪种领 |
|---|---|---|
| 职工养老缴满最低年限（15年/逐步20年） | 居民账户**全部余额**并入职工账户；**居民年限不算进职工年限** | 按**职工**待遇领 ✅ |
| 职工养老不够最低年限 | 职工账户余额并入居民账户；**职工缴费年限合并算作居民年限** | 按**居民**待遇领 |
| 同一年重复缴了两种 | 只算职工年限，居民那份**个人缴费+集体补助退给你**（政府补贴不退） | — |
| 已经在领居民养老金，后来职工缴满了 | **优先保留职工**，终止居民关系，除政府补贴外余额退还，**已领的居民基础养老金要退回**（可从职工养老金里扣） | 职工 |

> 💡 实操建议：**别一边缴灵活就业职工、一边又给父母思路似的给自己缴居民**——重复那几年白扔补贴。年轻人锁定职工，临近60锁定居民。

### Q16：在邢台缴的，去北京/天津打工了，年限会丢吗？

**不会。**

- 养老：跨省就业办**养老保险关系转移接续**，缴费年限**累计计算**，退休时"分段计算、统一支付"，在哪领按"最后满10年地→户籍地"规则定
- 医保：同理可转移；职工医保断保**3个月内**接上居民医保，不设等待期
- 现在多数情况**不用跑腿**：国家社会保险公共服务平台、掌上12333、电子社保卡小程序都能线上申请转移

## 五、断缴后果速查表（收藏这一张就够）

| 险种 | 断缴会清零吗 | 真实后果 | 补救 |
|---|---|---|---|
| **职工养老** | ❌ 不清零 | 年限累计变慢，退休金变少；灵活就业当年一般不能补 | 接着缴，前后年限合并；到龄不够年限可延长缴费或转居民 |
| **城乡居民养老** | ❌ 不清零 | 丢当年**政府补贴**+少滚一年利息；60岁不满15年要**延后领** | 当年11月25日前补当年；往年补缴（2028年前窗口，无补贴） |
| **职工医保** | 个账❌不清零；**连续年限✅重算** | 断缴次月起**不能报销**；超3个月再接，视同重新参保，3—6个月等待期，报销比例/限额可能降级 | 3个月内接上最划算；离职可选灵活就业职工医保或转居民医保 |
| **城乡居民医保** | 无个账，谈不上清零 | **固定3个月+每断1年加1个月**等待期，期内住院全自费；大病保险限额可能下调；连断4年修复后仍≥6个月 | 每年集中期（10.10—次年1月底）缴400元；多缴1年可修复1个月变动等待期 |
| **工伤/生育/失业** | — | 断缴期间出事**完全没有保障**，工伤费用只能找单位（单位没缴的由单位全赔） | 只能在职时有，重点看单位缴没缴 |

**三句辟谣**：

1. "社保断缴3个月全部清零"——**谣言**，养老一分不少，医保个账还在
2. "新农合不生病就是白交"——400元买的是**全年住院+大病兜底**，等待期里一场肺炎自费过万很常见
3. "农村户口交职工社保吃亏"——**反了**，只要单位缴，个人只出8%，是性价比最高的一份

|---|---|

## 七、常见疑难快答（附加10问）

**Q：地让征了（征地），社保怎么办？**
被征地农民有专门政策：进单位就业→参加职工五险；未就业转城镇居民→参加城居保+居民医保，保留农村身份→继续新农保口径，且政府一般会从土地补偿款里划一笔**被征地农民养老保险补贴**进你账户，别忘去村委问这笔钱到没到。

**Q：在外打工，村里还催我交居民养老，交不交？**
单位已给你缴**职工养老**的年份，**不用再交居民**，重复只退个人部分、白丢补贴。把单位缴费截图发给村代办员即可停保。

**Q：灵活就业职工医保 vs 居民医保，选哪个？**
一年约缴4000—5000元（职工）vs 400元（居民）。**身体一般、常跑医院、有慢性病门诊** → 职工医保报销比例高、有个人账户、缴满年限退休后免缴；**年轻力壮、预算紧** → 居民医保400元兜底，把省下的钱加码缴居民养老高档。

**Q：老人80多岁没缴过一分钱，能领吗？**
2014年制度实施时**已满60周岁**的，不用缴费，**直接按月领基础养老金**（条件是其符合参保条件的子女已参保缴费，多数河北县已放宽为直接发放），去村里登记即可。

**Q：改名字/身份证号升位/户口从甲村迁乙村，影响吗？**
姓名、身份证号变更必须去乡镇社保所办**参保信息变更**，否则缴费进不了账户；**同县内迁户口**不影响，**跨县/跨省迁**要把居民养老关系一并转过去（在户籍地申请）。

**Q：一年能改几次缴费档次？**
**当年缴完就不能改**，下手前想清楚；下一年可重新选。

**Q：交高档会不会"亏本"？**
不会。个人缴费+政府补贴+利息**全部进个人账户**，人走了**余额全额继承**，最差情况是"本金还给自己"，不存在打水漂。

**Q：医保报销能在邢台看北京吗？**
能。河北智慧医保小程序或国家医保服务平台App办**异地就医备案**（长期居住/转诊/临时外出三种），备案后在异地联网医院直接刷卡结算，不备案回去手工报，比例要降10—20个点。

**Q：领养老金的老人每年要干嘛？**
**待遇资格认证**，一年至少2次、间隔不超6个月。河北智慧医保/电子社保卡刷脸1分钟搞定，不会用手机的找村代办员，超期会**暂停发放**（补认证后补发，但会断一两个月现金流）。

**Q：去哪儿问最准？**
- 政策：村委会计/乡镇行政综合服务中心、**12333**（人社）、**12393**（医保）
- 缴费与到账：**河北税务**公众号、**河北智慧医保**小程序、支付宝"河北社保云缴费"
- 各县当年档次、基础养老金、截止日**以本县人社局+税务局通告为准**（如清河县2026年就是9.15—11.25）

1. **养老断缴不清零，但补贴和利息真金白银在流走**；60岁前凑满15年是硬底线，2028年前是补缴窗口期。
2. **医保断缴才最凶**：400元省下的，可能换来3—6个月"住院全自费"，全家老小**每年10—12月一起缴掉**，别拖。
3. **只要你跟单位有劳动关系，五险是法定的**，农村户口不是老板少缴的借口；年轻时在厂里缴职工养老，是这辈子回报率最高的一笔储蓄。
