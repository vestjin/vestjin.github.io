# 厨房笔记：辣椒选型与辣度指南（煮粉 / 煮面 / 炒菜）

> 辣度单位为斯科维尔（SHU），同品种受产地、成熟度影响会有浮动，以下为常见参考范围。
> 选椒心法：**要香选"长条椒"，要辣选"小个头"，要酸选"腌制货"，要色选"干红椒"。**

---

## 三、场景一：煮粉

| 粉的做法           | 推荐辣椒        | 配比 / 做法                                              |
| ------------------ | --------------- | -------------------------------------------------------- |
| 清汤汤粉（鲜辣派） | 小米辣          | 出锅前撒辣椒圈 5–8 个 + 蒜末 + 葱花，或加一勺油辣子      |
| 酸辣粉             | 油辣子 + 花椒面 | 辣椒面选秦椒/线椒（香而不燥）+ 保宁醋 + 芽菜，醋临出锅放 |
| 螺蛳粉             | 剁椒 / 小米辣   | 酸笋是灵魂，辣油包外再加鲜椒提辣                         |
| 南昌拌粉 / 卤粉    | 剁椒            | 剁椒 + 萝卜干 + 花生米 + 小葱，拌匀即食                  |
| 沾水粉（云贵风）   | 糊辣椒面        | 糊辣椒 + 折耳根 + 薄荷 + 木姜子油，蘸着吃                |

**要点**：米粉本身味淡，靠"鲜辣 + 酸"提味；辣度不够优先加小米辣圈，而不是狂加油辣子（会腻）。

## 四、场景二：煮面

| 面的做法        | 推荐辣椒        | 配比 / 做法                                                  |
| --------------- | --------------- | ------------------------------------------------------------ |
| 油泼面          | 粗细辣椒面      | 粗:细 = 7:3，加白芝麻、五香粉、盐，菜籽油 180℃ 分两次泼（一次激香、一次激色） |
| 担担面 / 红油面 | 二荆条 + 子弹头 | 干椒比例 二荆条 5 : 子弹头 2 : 花椒 1，炼红油                |
| 牛肉面 / 杂酱面 | 干辣椒段 + 豆瓣 | 郫县豆瓣 + 干辣椒段煸香做臊子底                              |
| 酸辣面 / 酸汤面 | 泡椒末          | 泡椒 + 陈醋 + 一点点糖合味                                   |
| 清汤面改良      | 油辣子          | 不改汤底，一勺油辣子或几片小米辣即可                         |

**要点**：煮面的辣讲究"香辣挂面"，辣椒面比鲜椒更挂味；干辣椒先用温水泡软再打碎，出香不出糊。

## 五、场景三：炒菜

| 菜式                  | 推荐辣椒                        | 做法要点                         |
| --------------------- | ------------------------------- | -------------------------------- |
| 辣椒炒肉 / 小炒黄牛肉 | 螺丝椒 + 小米辣（3:1）          | 大火煸出虎皮，起锅前才放小米辣圈 |
| 回锅肉 / 麻婆豆腐     | 二荆条 + 郫县豆瓣               | 香辣不燥，豆瓣小火炒出红油       |
| 干锅 / 辣子鸡         | 干辣椒段（子弹头/新一代）+ 花椒 | 剪段去籽可减辣 30%，小火煸至棕红 |
| 剁椒鱼头 / 剁椒蒸菜   | 剁椒 + 蒜末                     | 剁椒本身有咸味，少放盐           |
| 泡椒鸡杂 / 泡椒牛肉   | 泡椒段 + 泡姜                   | 酸辣出锅气，全程大火快炒         |
| 炝炒时蔬              | 干辣椒段 + 蒜片                 | 低温炝锅，只取香不取辣           |
| 虎皮青椒 / 擂椒皮蛋   | 杭椒 / 皱皮椒                   | 干煸去皮，微辣配皮蛋             |

**要点**：炒菜辣度 = 辣椒品种决定 70%，火候与投放时机决定 30%。鲜辣怕久炒变暗，起锅前放；干辣要低温煸，高温易焦苦。

## 六、家庭常备组合（一套走天下）

1. **鲜辣**：小米辣（洗净晾干冷冻，随取随用）
2. **增香**：螺丝椒（炒菜）+ 二荆条或干辣椒段（炝锅）
3. **酸辣**：剁椒一瓶 + 泡椒一袋
4. **万能**：油辣子一瓶（粗细辣椒面 7:3，白芝麻 + 少许盐 + 菜籽油 180℃ 两次泼）

## 七、实用技巧

- **减辣**：去籽去白筋能减辣约一半；冷水泡 10 分钟再用
- **增香不增辣**：干辣椒煸香后捞出，或只用辣椒面泼油
- **油温口诀**：160–180℃ 泼辣子，温度不够不香，过高发苦
- **辣了怎么办**：喝牛奶、酸奶或含糖饮料（辣椒素溶于油脂不溶于水，喝水无效）
- **选购**：鲜椒选颜色油亮、捏起来有弹性、蒂部鲜绿的；干椒选暗红有光泽、无霉斑的
- **储存**：鲜椒冷冻，干椒密封避光，剁椒/泡椒开罐后冷藏并用干净勺取用
