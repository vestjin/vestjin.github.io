

## ️ 一、手机端设置优化

刚入坑建议先调整以下关键设置：

- **关闭"自动购买经验"**：防止误升人口打乱运营节奏
- **开启"装备合成提示"**：避免合错装备浪费资源
- **画面调成"中"档**：兼顾流畅度和省电
- **备战席最多存10个棋子**：无关棋子及时卖掉，不要过度囤积

>  如果手机屏幕偏小觉得操作不便，后期也可以考虑用模拟器在电脑上玩，大屏观察棋盘和羁绊更清晰，键鼠操作也更精准。

## 二、经济管理（核心中的核心）

经济是金铲铲的灵魂，掌握以下几个关键原则：

### 金币来源

| 来源      | 说明                             |
| --------- | -------------------------------- |
| 基础金币  | 每回合固定获得（2-1后每回合5金） |
| 利息      | 每10金币产生1利息，上限5金       |
| 连胜/连败 | 连胜或连败额外奖励金币           |
| 野怪法球  | 每阶段末打野怪掉落，第一时间去捡 |
| 强化符文  | 部分海克斯直接给金币或经验       |

### 关键技巧

- **50金吃满利息**：50金是存钱底线，利息收益远大于盲目搜牌
- **敏感数字33金**：33金 + 3利息 + 5基础收入 = 41金（下回合吃4利息），再下回合 = 50金吃满利息。这是高手常用的卡经济技巧
- **野怪法球别忘捡**：打完野怪第一时间去拿法球，不需要的装备可以卖掉凑整十金币
- **点击金币旁的小火焰**：可以查看收入明细，别只看余额

### 什么时候该花钱？

- **血量 > 40**：继续存钱上人口找高费C位
- **血量 < 40**：优先搜牌保血，别贪利息
- **连胜期间**：升级带来的战力提升 > 几块钱利息，该升就升

## ️ 三、装备分配策略

### 选秀优先级

> 大剑 > 反曲弓 > 拳套 > 眼泪（这四件适配阵容最多）

### 分配原则

- **先做前排装备**（狂徒、反甲、龙牙），再给主C做输出装
- **装备集中给主C**：主C凑3件，前排凑2件，不要分散
- **通用神装**：羊刀（大棒+反曲弓）、朔极之矛（大剑+女神泪）适配多数C位
- **前期别死追3星**：2星够用，把资源留给核心高费卡
- **金铲铲是特殊装备**：两件可合成"自然之力"增加人口上限

## 四、站位技巧

### 常规站位

- **坦克**：顶前排左右两侧
- **近战输出**：站前排后方一格
- **远程C位**：缩后排角落

### 针对性调整

- **防刺客**：刺客跳最后一排，把主C往前挪一格或放角落，用坦克夹住保护
- **防钩子（锤石/机器人）**：放一个无关紧要的英雄在角落吸引钩子
- **分散站位**：避免被对手AOE技能一波带走
- **决赛圈**：观察对手站位，灵活调整位置躲控制和刺客

> ️ 注意镜像关系：你站棋盘左边，对手看到的是右边，利用这点预判对手攻击方向。

## 五、运营节奏

### 人口升级节奏

| 阶段 | 操作    |
| ---- | ------- |
| 2-1  | 升4人口 |
| 2-5  | 升5人口 |
| 3-2  | 升6人口 |
| 4-1  | 升7人口 |
| 5-1  | 升8人口 |

### 连胜运营

前期用强势羁绊和高质量打工卡维持连胜，严格控制经济。2-5阶段至少10金，2-6阶段应达20金以上，用利息升级和搜牌。

### 连败运营

前期空城或低质量阵容保经济，利用连败奖励和优先选秀权快速积累金币，在3-2至4-1阶段升到6-8人口后搜卡锁血。注意控制血量别过早出局。

### 通用建议

- **有啥玩啥**，别死磕一套阵容，根据发牌灵活凑羁绊
- **海克斯优先选加经济/加战力的**，别选花里胡哨的
- **每回合花3秒观察对手**，针对性调整站位
- 新手建议先练一套简单阵容，去匹配模式练10把再打排位

## 二、**“花仙小炮”阵容**

**核心是4花仙子羁绊配合三星崔丝塔娜打钱流，靠经济优势快速滚人口拉上限**

### 阵容构成

- **核心羁绊**：4花仙子、3约德尔人和朋友、2猎人
- **主C**：三星崔丝塔娜（羊刀+科技枪+海妖之怒
- **前排**：三星拉莫斯（石像鬼+振奋+狂徒）、三星蔚（谁三星谁主坦https://news.qq.com/rain/a/20261002A09Z7Q00)
- **副C**：希维尔（红霸符+轻语+朔极之矛）
- **挂件**：莉莉娅（中期凑4花仙）、纳尔/艾翁（后期补上限）、洛/霞（前期过渡）

### 玩法机制

- **4花仙子**：吸满7个皮克斯仙灵后，开始吸引黄金皮克斯仙灵并掉金币
- **花仙小炮**：三星小炮无限射程点人，花仙负责打钱，前排扛伤，经济滚起来直接上9人口 
- **节奏**：前期抓羊刀过渡小炮，中期追三拉莫斯和蔚，7层后挂4花仙，三星后靠打钱拉上限 

### 运营步骤

1. **开局抢羊刀**：反曲之弓+无用大棒给小炮，快速叠仙灵层数
2. **中期追三**：7人口搜两星小炮、拉莫斯、蔚，优先赌三星
3. **挂4花仙**：莉莉娅上场或仙灵到7层后再挂，避免前期白回血
4. **打钱上9**：三星后全钱滚人口，补纳尔、艾翁等五费挂件

### 装备分配

- **崔丝塔娜**：羊刀、科技枪、海妖之怒
- **拉莫斯**：石像鬼、振奋、狂徒
- **希维尔**：红霸符、轻语、朔极之矛

**总结**：自然之力花仙子组合的核心是“4花仙子打钱+三星小炮主C”，靠经济优势滚人口，最终用纳尔、艾翁等五费补上限，是一套官方A级、节奏清晰的上分阵容
